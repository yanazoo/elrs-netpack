# ELRS-NETpack v2.3.7 — いちばん電波の強い AP につなぐ / Join the strongest access point

> **Language / 言語:** [日本語](#日本語) | [English](#english)

---

<a name="日本語"></a>

## 日本語

### 変更（クライアントモード）

- WiFi につなぐとき、**全チャンネルを探して、電波が一番強い AP** につなぐようにしました。これまでは最初に見つけた AP につないでいたので、メッシュ WiFi や中継器で同じ SSID の AP が複数あると、遠い方につながることがありました（FPV C5 Lap Timer と同じ動きです）。
  - つなぎ直すときも同じです。
  - つなぐまでの時間は、全チャンネルを探す分（1〜2 秒）長くなります。
- つながったときのログに、つないだ AP（BSSID）・チャンネル・電波の強さ（dBm）を出します。

### 対応するファームウェア

netpack の XIAO を書き換えてください（通常版・タイマー流用版とも同じ変更）。ブリッジは書き換え不要です。

### 動作確認

- 通常版・タイマー流用版のビルドと、実機での動作を確認しました。

## English

### Changes (client mode)

- Joining a network now scans **every channel and takes its strongest access point**; the first one heard used to be joined, so with a mesh or a repeater (several access points of one SSID) the far one was joined as often as the near one (as FPV C5 Lap Timer does).
  - The same when reconnecting.
  - Joining takes the scan's 1-2 s longer.
- The log on joining names the access point (BSSID), channel and signal (dBm).

### Matching firmware

Update the netpack XIAO (the same change in the standard and timerwiring builds). The bridge needs no update.

### Verified

- Both builds, and on hardware.
