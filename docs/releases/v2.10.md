# v2.10 — netpack XIAO：アポストロフィ入りの SSID と、新しい接続の取りこぼしを修正

### 🐞 修正（netpack XIAO `elrs-xiao-webui/`）

- **アポストロフィ入りの SSID が壊れる**
  - WiFi 設定ページは、保存した SSID をそのまま入力欄に入れていました。SSID に `'` があると（例：`John's iPhone`）そこで途切れ、入力欄には `John` と表示されます。
  - そのままパスワードだけ変えて保存すると、SSID が `John` に書き換わっていました。
  - SSID を正しく表示するように直しました。
- **新しい TCP 接続の最初のデータを取りこぼす**
  - 前の接続が途中まで送ったデータが残り、新しい接続の最初のデータ（バージョンの問い合わせ）を飲み込んでいました。
  - 返事を待つ接続元（RotorHazard の vrxc_elrs）は、その接続に失敗していました。
  - 新しい接続ごとに、読み取りを最初の状態に戻すようにしました。

### ✅ 動作確認

- SSID の置き換え処理を PC でコンパイルして確認しました。
- 実機で、netpack 経由のタイマー・RotorHazard との接続を確認しました。
