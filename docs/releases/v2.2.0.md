# v2.2.0 — netpack XIAO：ホストモード（netpack の WiFi にタイマーとスマホが接続）と USB テザリング

### ✨ 新機能（netpack XIAO `elrs-xiao-webui/`）

- **ホストモード**：netpack の XIAO が自分の WiFi を出します（WiFi 設定 →「接続方式」→ ホスト）。
  - タイマー（FPV C5 Lap Timer）は**クライアントモード**でこの WiFi に接続します。netpack アドレスは `auto` のまま（`elrs-netpack.local` で見つけます）。
  - タイマーからの MSP は今まで通り UART → ESP-NOW ブリッジ → ゴーグルへ届きます（ブリッジの ESP-NOW はチャンネル 1 のまま）。
  - SSID・パスワード（8〜63 文字）・チャンネル（6〜11 ch）を設定できます。初期値は `ELRS-Netpack` / `elrs-netpack` / 6 ch。接続はタイマーを含めて 10 台まで。
  - 設定ページ（`http://192.168.4.1/`）に、つながっている機器と、MSP の接続元（タイマー）の「**タイマーを開く**」リンクが出ます。
- **USB テザリング**（ホストモードのみ、設定で ON / OFF、初期値 OFF）：XIAO の USB-C に Android スマホをつないで「USB テザリング」を ON にすると、netpack の WiFi の機器（タイマー・スマホ）がスマホ経由でインターネットへ出られます。
  - RNDIS（多くの Android）と CDC-NCM / ECM（新しい Pixel など）に対応。iPhone は非対応です。
  - 機器からの DNS をスマホの DNS へ中継し、通信をスマホ経由で外へ出します（NAPT）。
  - XIAO に **USB-C → USB-A の OTG 変換アダプター**、スマホは充電ケーブル（USB-A → スマホ）でつなぎます。スマホが認識するには、XIAO の **5V ピンから給電**して USB の VBUS に 5V を出す必要があります（README を参照）。
  - ON の間、USB はシリアル・書き込みに使えません。ログは D6（UART0 TX、115200）に出ます。
- **ファームの書き込み方法を増やしました**（設定はどれもそのまま）：
  - **Web 書き込みページ**（https://yanazoo.github.io/elrs-netpack/ 、PC の Chrome / Edge）：netpack XIAO・ESP-NOW ブリッジ（C3 / Wrover-E）の最新版を、USB でつないで書き込めます。
  - 同じページの「**ファイルを指定して書き込む**」：手元の .bin（試験版・前の版）やリリースの zip を選んで書き込めます。アドレスはファイル名から自動で入り（変更可）、firmware.bin には「最初のアプリから起動」（otadata）を自動で付けます。
  - netpack の設定ページの「**更新**」：「🔍 最新版を確認」→「⬇️ 〜に更新」のボタンでネットから更新（インターネットが必要）、または firmware.bin のファイルから更新。
- リリースに、ビルド済みのファイル（zip・`*-full.bin`・ネット更新用）が付くようにしました（GitHub Actions でビルド）。

### 🔧 変更

- netpack XIAO のビルドを pioarduino（Arduino-ESP32 3.3.5）にしました（USB ホストと NAPT を使うため）。今まで通り PlatformIO の `xiao_esp32s3` で書き込めます。
- ESP-NOW ブリッジ（`elrs-espnow-bridge/`）は変更なし（v2.12 のまま）。

### ✅ 動作確認

- XIAO ESP32-S3・ESP-NOW ブリッジ（Wrover-E・XIAO C3）のビルドと、Web 書き込みページの作成を確認しました。
- ブラウザーで、Web 書き込みページの「ファイルを指定して書き込む」（zip を分けてアドレスを入れる・otadata を付ける・重なりの確認）を確かめました（実機への書き込みは未確認）。
- 実機での確認（ホストモードでタイマー・スマホの接続と OSD、USB テザリング）は、これから行います。
