# ELRS-NETpack v2.3.3 — WiFi をすべて 20 MHz 幅に / Every WiFi 20 MHz wide

> **Language / 言語:** [日本語](#日本語) | [English](#english)

---

<a name="日本語"></a>

## 日本語

### 変更

- **クライアントモード**（FPV C5 Lap Timer の WiFi・ルーターにつなぐとき）の WiFi を、**20 MHz 幅に固定**しました。これまでは指定がなく、2.4 GHz を 40 MHz で出しているルーターでは 40 MHz になることがありました。
- **設定用の WiFi**（`ELRS-NETpack-Setup`）も 20 MHz 幅にしました。
- ホストモードは v2.2.0 から 20 MHz 幅です。これで netpack の WiFi はすべて 20 MHz 幅になり、FPV C5 Lap Timer（v2.3.4 から）とそろいました。

20 MHz 幅は隣のチャンネルにかかりにくく、ESP-NOW（ch 1）や各パイロットの ELRS 2.4 GHz、会場の WiFi との干渉が減ります。netpack の通信量（OSD・設定ページ）には 20 MHz で十分です。40 MHz のルーターにも、そのまま（20 MHz で）つながります。

### 対応するファームウェア

netpack の XIAO を書き換えてください（「更新」ページ、または Web 書き込みページ）。通常版・タイマー流用版とも同じ変更です。ブリッジは書き換え不要です。

### 動作確認

- 通常版・タイマー流用版のビルドを確認しました。実機での確認をお願いします。

<a name="english"></a>

## English

### Changes

- **Client mode** (joining FPV C5 Lap Timer's WiFi or a router) is now **20 MHz wide**; it was unset, so a router on 40 MHz at 2.4 GHz could make it 40 MHz.
- The **setup WiFi** (`ELRS-NETpack-Setup`) is 20 MHz wide too.
- Host mode has been 20 MHz since v2.2.0: every netpack WiFi is now 20 MHz, as FPV C5 Lap Timer (since v2.3.4).

20 MHz stays off the neighbouring channels (ESP-NOW on ch 1, the pilots' ELRS 2.4 GHz, the venue's WiFi), and is plenty for the netpack's traffic. A 40 MHz router is still joined (on 20 MHz).

### Matching firmware

Update the netpack XIAO (its "Update" page, or the web flasher); the same change in the standard and timerwiring builds. The bridge needs no update.

### Verified

- Both builds. Please check on hardware.
