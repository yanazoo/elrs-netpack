# ELRS-NETpack v2.3.4 — XIAO 以外の ESP32-S3・ESP32-C5 ボードにも / Boards other than the XIAO (ESP32-S3, ESP32-C5)

> **Language / 言語:** [日本語](#日本語) | [English](#english)

<a name="日本語"></a>

## 日本語

### 追加

- **ブリッジ：ESP32-C5 汎用ボード・モジュール**（ESP32-C5-WROOM-1、Waveshare ESP32-C5-Zero など。フラッシュ 4MB 以上）。UART は **GPIO4（RX）・GPIO5（TX）**。Web 書き込みページのハードで「**ESP32-C5 汎用ボード・モジュール**」を選びます（リリースのファイルは `…esp32c5…`）。
  - FPV C5 Lap Timer の受信機（FPVGate C5MK の汎用 C5 版）と同じピンなので、XIAO ではない ESP32-C5 で組んだタイマーを netpack にするとき（タイマー流用版）のブリッジにもそのまま使えます。
- **netpack：ESP32-S3 モジュール・ボード**（ESP32-S3-WROOM-1(U)-N16R8 など、PSRAM 8MB オクタル、フラッシュ 8MB 以上）に、XIAO と同じファームを書き込めることを README と書き込みページに書きました。配線は XIAO と同じ **GPIO 番号**です。

### 対応するファームウェア

netpack のファームは v2.3.3 と同じです（書き換え不要）。汎用 ESP32-C5 をブリッジにする場合だけ、新しいハードを書き込みます。

### 動作確認

- すべてのビルドを確認しました。汎用 ESP32-C5・ESP32-S3 モジュールでの実機確認をお願いします。

## English

### New

- **Bridge: generic ESP32-C5 boards and modules** (ESP32-C5-WROOM-1, Waveshare ESP32-C5-Zero and the like; 4 MB flash or more). UART on **GPIO4 (RX), GPIO5 (TX)**. Pick "**ESP32-C5 汎用ボード・モジュール**" in the web flasher (release files `…esp32c5…`).
  - The same pins as FPV C5 Lap Timer's receiver on a generic C5 (FPVGate C5MK's generic build): a timer built on a non-XIAO ESP32-C5 made into a netpack (timerwiring) uses it as its bridge.
- **netpack: ESP32-S3 modules and boards** (ESP32-S3-WROOM-1(U)-N16R8 and the like; 8 MB octal PSRAM, 8 MB flash or more) take the XIAO's firmware as it is (README and web flasher); wire by the same **GPIO numbers**.

### Matching firmware

The netpack firmware is the same as v2.3.3 (no update needed). Only a generic ESP32-C5 bridge is new.

### Verified

- Every build. Please check on a generic ESP32-C5 and an ESP32-S3 module.
