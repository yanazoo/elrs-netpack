# ELRS-NETpack v2.3.2 — FPV C5 Lap Timer を netpack にする「タイマー流用版」 / The "timerwiring" build: an FPV C5 Lap Timer made into a netpack

> **Language / 言語:** [日本語](#日本語) | [English](#english)

---

<a name="日本語"></a>

## 日本語

### 追加

- **タイマー流用版**：ブリッジを付けずに組んだ FPV C5 Lap Timer（XIAO ESP32-S3 ＋ XIAO ESP32-C5）を、**配線を変えずに** netpack にできるようになりました。S3 が netpack、C5 が ELRSバックパック-ブリッジになります。機能は通常の netpack と同じです。
  - UART はタイマーの配線のまま（S3 D3/D4 ⇔ C5 D4/D5）。
  - 任意の追加部品は空いているピンへ：ブザー D5（GPIO6、− は GND）、モード切り替えスイッチ D1（GPIO2）、通知 LED D0（GPIO1）、LiPo 電圧 D2（GPIO3）。
  - 電源はタイマーと同じ 5V。
- **Web 書き込みページ**：ELRS-NETpack に「配線：通常 / タイマー流用」、ブリッジに「XIAO ESP32-C5（タイマー流用）」を追加しました。
- **リリースのファイル**：通常版とタイマー流用版の両方が付きます（`…xiao_esp32s3_timerwiring…`、`…xiao_esp32c5_timerwiring…`、ネット更新用の `elrs-netpack-xiao_esp32s3-timerwiring-firmware.bin`）。

### 更新の安全

- netpack の「ネットから更新」は、自分の版（通常 / タイマー流用）のファイルを取りに行きます。そのリリースにタイマー流用版が無いときは、書き込まずに知らせます。
- 「ファイルから」は、ファイルの中の目印を見て、**違う版のファイルは書き込む前に止めます**（ピンが違うため、書き込むと動かなくなります）。目印の無いファイル（v2.3.1 以前）は通常版として扱います。
- 更新ページと状態の表示に「タイマー流用版」と出ます。

### 対応するファームウェア

通常の netpack は書き換え不要です（v2.3.1 と同じ動きです）。タイマーを netpack にする場合は、S3・C5 の両方を Web 書き込みページから書き込みます（一度「デバイスを消去する」にチェックを入れるとタイマーの設定が残りません）。

### 動作確認

- 通常版・タイマー流用版のビルドと、更新ファイルの判定（実際の両方の firmware.bin を、いろいろな区切りで読ませて確認）を確認しました。実機での確認をお願いします。

## English

### New

- **The timerwiring build**: an FPV C5 Lap Timer built without a bridge (XIAO ESP32-S3 + XIAO ESP32-C5) becomes a netpack **with no rewiring**: the S3 runs the netpack, the C5 the ELRS Backpack bridge. It works as any netpack.
  - UART on the timer's wires (S3 D3/D4 ⇔ C5 D4/D5).
  - Optional parts on free pins: buzzer D5 (GPIO6, − to GND), mode switch D1 (GPIO2), notification LED D0 (GPIO1), LiPo voltage D2 (GPIO3).
  - Power as the timer: 5V.
- **Web flasher**: ELRS-NETpack has "wiring: standard / timer's", the bridge "XIAO ESP32-C5 (timer's wiring)".
- **Release files**: both builds (`…xiao_esp32s3_timerwiring…`, `…xiao_esp32c5_timerwiring…`, and `elrs-netpack-xiao_esp32s3-timerwiring-firmware.bin` for the online update).

### Safe updates

- The online update takes this netpack's own build (standard / timerwiring); a release without the timerwiring file is reported, nothing written.
- "From a file" looks for the build's mark in the file and **refuses the other build's file before writing it** (its pins differ). A file with no mark (v2.3.1 and older) counts as the standard build.
- The update page and the status show "timerwiring".

### Matching firmware

A standard netpack needs no update (it works as v2.3.1). To make a timer into a netpack, write both the S3 and the C5 from the web flasher (tick "Erase device" once so nothing of the timer's settings stays).

### Verified

- Both builds, and the file check (on both real firmware.bin files, read in various chunk sizes). Please check on hardware.
