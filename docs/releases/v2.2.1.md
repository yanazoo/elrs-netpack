# v2.2.1 — ESP-NOW ブリッジを XIAO ESP32-C5 でも／書き込みページのブリッジをハード選択に

### ✨ 新機能

- **ESP-NOW ブリッジが XIAO ESP32-C5 でも動くようにしました**（PlatformIO 環境 `xiao_esp32c5`）。
  - 配線は XIAO C3 と同じ D7（GPIO12、RX）・D6（GPIO11、TX）・GND です。
  - C5 は 5 GHz も使えますが、ブリッジは 2.4 GHz のチャンネル 1 だけを使います（バックパックと同じ）。
- **Web 書き込みページ**：ESP-NOW ブリッジを 1 つの欄にまとめ、ハード（XIAO ESP32-C3 / XIAO ESP32-C5 / ESP32 Wrover-E）を選んで書き込むようにしました。「ファイルを指定して書き込む」の機器にも C5 のブリッジを加えました。

### 🔧 変更

- ブリッジの動作（OSD の送信・スイッチ・リンクの見張り）は v2.2.0 と同じです。C3・Wrover-E は書き換え不要です。
- netpack XIAO（`elrs-xiao-webui/`）は v2.2.0 と同じです。

### ✅ 動作確認

- XIAO ESP32-C5・C3・Wrover-E のブリッジ、netpack XIAO のビルドを確認しました。
- C5 のブリッジの実機での確認は、これから行います。

**書き込み対象**
- XIAO ESP32-C5 をブリッジに使う場合のみ、そのボードに書き込みます。
