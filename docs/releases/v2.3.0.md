# v2.3.0 — netpack XIAO：WiFi の接続先を 5 件に・IP アドレスの固定

### ✨ 新機能（netpack XIAO `elrs-xiao-webui/`、クライアントモード）

FPV C5 Lap Timer と同じ WiFi 設定にしました（WiFi 設定ページの「クライアント」）。

- **接続先を 5 つまで登録**できます（SSID・パスワード）。
  - パスワードは表示しません。変えないときは空欄のままで保存します。SSID を消すと、その接続先は削除されます。
  - **接続先の選び方**：
    - **選んだもの（●）**：● を付けた接続先につなぎます。
    - **自動**：つなぐときに周りを探して、登録した中で電波が一番強い接続先につなぎます（例：会場のルーターと、スマホのテザリングの両方を登録しておく）。
  - どれにもつながらないときは、今まで通り設定用 AP（`ELRS-Netpack-Setup`）を出し、15 秒ごとに接続先を探し直します（自動のときは毎回いちばん強いものを選び直します）。
- **IP アドレスの固定**：「IP アドレス」を**固定**にして、IP アドレス・サブネットマスク・ゲートウェイ・DNS（空欄ならゲートウェイ）を入れます。登録したすべての接続先で同じアドレスを使います。
  - タイマーの「netpack アドレス」に固定した IP を直接入れておけば、mDNS で探さずにすぐつながります。
- v2.2.x で保存していた接続先は、**1 件目にそのまま引き継がれます**（設定し直す必要はありません）。
- WPA だけの古いルーターにもつながるようにしました。

### 🔧 変更

- ホストモードの WiFi の**初期値**を、SSID **`ELRS-NETpack`**・パスワード `elrs-netpack` にしました（SSID の大文字・小文字が変わりました）。
  - 一度でも WiFi 設定ページで保存した netpack は、保存した SSID（今までの `ELRS-Netpack` など）のままです。変えるときは、WiFi 設定ページの「ホスト」の SSID を書き換えて保存してください。
- USB テザリング・更新ページは v2.2.x と同じです。
- ELRSバックパック-ブリッジ（`elrs-espnow-bridge/`）は変更なし。
