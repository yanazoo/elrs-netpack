# v2.3.0 — netpack XIAO：WiFi の接続先を 5 件に・IP アドレスの固定

### ✨ 新機能（netpack XIAO `elrs-xiao-webui/`、クライアントモード）

FPV C5 Lap Timer と同じ WiFi 設定にしました（WiFi 設定ページの「クライアント」）。

- **接続先を 5 つまで登録**できます（SSID・パスワード）。
  - パスワードは表示しません。変えないときは空欄のままで保存します。SSID を消すと、その接続先は削除されます。
  - **接続先の選び方**：
    - **選んだもの（●）**：● を付けた接続先につなぎます。
    - **自動**：つなぐときに周りを探して、登録した中で電波が一番強い接続先につなぎます（例：会場のルーターと、スマホのテザリングの両方を登録しておく）。
  - どれにもつながらないときは、今まで通り設定用 AP（`ELRS-NETpack-Setup`）を出し、15 秒ごとに接続先を探し直します（自動のときは毎回いちばん強いものを選び直します）。
- **IP アドレスの固定**：「IP アドレス」を**固定**にして、IP アドレス・サブネットマスク・ゲートウェイ・DNS（空欄ならゲートウェイ）を入れます。登録したすべての接続先で同じアドレスを使います。
  - タイマーの「netpack アドレス」に固定した IP を直接入れておけば、mDNS で探さずにすぐつながります。
- v2.2.x で保存していた接続先は、**1 件目にそのまま引き継がれます**（設定し直す必要はありません）。
- WPA だけの古いルーターにもつながるようにしました。
- **設定ページのいちばん上に「FPV C5 Lap Timer」の画面へのリンク**を出すようにしました（クライアント・ホストどちらのモードでも）。
  - MSP でつながっていればその相手、つながっていなくても同じ WiFi にいれば名前（`fpv-c5-lt.local`）で探して表示します。見つからないときは「見つかりません（同じ WiFi につないでください）」と出ます。
  - 画面の表記を「タイマー」から「FPV C5 Lap Timer」に統一しました（README も同じ）。
- **ホストモードの接続台数**（WiFi 設定 →「ホスト」→「スマホ・PC の接続台数」、1〜9 台、**初期値 5 台**）：ブリッジとして使うための制限です。
  - **FPV C5 Lap Timer の 1 台分はいつも空けておき**、スマホ・PC は設定した台数までにします。上限を超えてつないだ機器は外し、30 秒間は入れません。
  - FPV C5 Lap Timer は、OSD の接続（TCP）をしてきた機器として覚えておきます（一度つながったあとは、台数の制限で外されません）。
  - netpack の WiFi で大勢が観戦するときは、台数を増やしてください（WiFi 全体で最大 10 台）。
- **FPV C5 Lap Timer との接続が切れたときの通知**（ブザーの長音 5 回と LED の中速点滅、つながり直すまで点滅）を、ホストモードでもすぐ出るようにしました。FPV C5 Lap Timer が netpack の WiFi から抜けたら、TCP のキープアライブ（約 11 秒）を待たずに、すぐ知らせます。クライアントモードは今まで通り（約 11 秒）です。

### 🔧 変更

- ホストモードの WiFi の**初期値**を、SSID **`ELRS-NETpack`**・パスワード `elrs-netpack` にしました（SSID の大文字・小文字が変わりました）。
  - 一度でも WiFi 設定ページで保存した netpack は、保存した SSID（今までの `ELRS-Netpack` など）のままです。変えるときは、WiFi 設定ページの「ホスト」の SSID を書き換えて保存してください。
- 設定用の WiFi（クライアントモードでつながらないときに出る WiFi）の名前を **`ELRS-NETpack-Setup`** にしました（パスワード `elrs-netpack` は同じ）。こちらは保存した設定に関係なく、書き換えるとすぐ新しい名前になります。
- **モード切り替えの物理スイッチ**（任意）：設定ページで「物理スイッチを使う」にチェックを入れると（初期値はなし）、D4（GPIO5）と GND の間のスイッチで、**ON（つながる）ならホストモード、OFF ならクライアントモード**で起動します。スイッチは起動したときだけ読みます（切り替えは再起動後に反映）。
- **QR タブ**（`/qr`）を加えました。ELRS-NETpack の WiFi（ホストモードの SSID・パスワード）に接続する QR コードと、FPV C5 Lap Timer の画面（`http://fpv-c5-lt.local/`）を開く QR コードを出します。QR コードは netpack の中で作るので、インターネットがなくても表示できます。
- **ホストモードの WiFi に PC がつながるのが遅い**（Windows の「ネットワークの要件をチェックしています」が長い）のを直しました。インターネットへの出口がないとき、netpack は名前の問い合わせ（DNS）に「失敗」とだけ返していたため、Windows が何度も問い合わせ直していました。FPV C5 Lap Timer のホストモードと同じく、どの名前にも netpack のアドレスを返すようにしました（USB テザリングでつながっているときは、今まで通りスマホの DNS へ中継します）。あわせて、WiFi の始め方（アドレス設定 → WiFi の順）と電波の幅（20 MHz）も FPV C5 Lap Timer と同じにしました。
  - `.local` の名前は netpack が答えます：`fpv-c5-lt.local` は **FPV C5 Lap Timer の本当のアドレス**、`elrs-netpack.local` は netpack 自身、それ以外の `.local` は「ない」と返します（スマホや PC が自分で mDNS で探します）。mDNS に対応していない Android でも、QR タブの `http://fpv-c5-lt.local/` で FPV C5 Lap Timer の画面が開けます。
- 設定ページの「この WiFi の機器」で、まだアドレスを受け取っていない機器を「0.0.0.0」ではなく「アドレス未取得」と表示するようにしました。
- **管理者パスワード**：QR 以外のページ（WiFi・電圧・更新）は、ログインしてから開けるようにしました。QR ページはパスワードなしで見られ、ホストモードで `http://192.168.4.1/` を開くと最初に QR ページが出ます。**初期パスワードは `admin`**（公開している値です）。WiFi のページの「管理者パスワード」で**変更してください**（初期値のままだと注意が出ます）。ログインは 12 時間（または再起動まで）有効です。
- 「更新」ページの「ファイルから」で、**書き込みの進み具合（%）**を出すようにしました。書き込みが終わると「再起動しています…」と出て、再起動が終わるとページを読み直します。
- 設定ページと Web 書き込みページの名前を **「ELRS-NETpack」** にしました（ブラウザーのタブにも「ELRS-NETpack — ページ名」と出ます）。
- USB テザリング・更新ページは v2.2.x と同じです。
- ELRSバックパック-ブリッジ（`elrs-espnow-bridge/`）は変更なし。
