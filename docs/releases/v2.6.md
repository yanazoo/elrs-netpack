# v2.6 — 表示漏れの修正（v2.5 の送信スキップ条件を見直し）

### 🐞 修正：レースクロックの秒が飛ぶ・ラップタイムが出ないことがある（v2.5 の不具合）

v2.5 では、応答しないゴーグル宛ての送信が詰まらないよう、**パケットが 1 回でも送信失敗すると、そのバーストの残りを捨てる**ようにしていました。

ところが、電源が入っているゴーグルでも、パケットや ACK はときどき失われます。そのとき捨てた残りには「表示」コマンドも含まれるため、**画面更新が丸ごと失われ**、レースクロックの秒が飛んだり、ラップタイムが表示されなかったりしていました。

- バーストの残りを飛ばすのは、**同じ宛先で 3 回連続して送信に失敗したとき**だけにしました。1 回でも成功すれば、連続カウントはリセットされます
- 飛ばし中の宛先に次のバーストが来たら、1 回だけ送信を試します。また失敗したら再び飛ばします（電源オフのゴーグルにかかる時間は小さいままです）
