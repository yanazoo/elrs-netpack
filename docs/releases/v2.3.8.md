# ELRS-NETpack v2.3.8 — お知らせ音が重ならないように、USB テザリングの削除、ボタンの大きさ / Beeps no longer run together, USB tethering removed, one size of buttons

> **Language / 言語:** [日本語](#日本語) | [English](#english)

<a name="日本語"></a>

## 日本語

### 修正

- クライアントモードで WiFi につながったとき、お知らせ音が「ピッ・ピッ」と正しく鳴るときと、「ピピピッ」と間のない速い音になるときがありました。
  - 原因：WiFi につながった音（短く 2 回）の途中で、FPV C5 Lap Timer がつないできた音（短く 1 回）が来ると、鳴っている音を途中で打ち切って最初から鳴らし直していました。
  - 今は、鳴っている途中に次の音が来たら**順番待ち**にして、今の音を最後まで鳴らし、少し間（0.25 秒）をあけてから次を鳴らします。いつも「ピッ・ピッ（WiFi）…ピッ（FPV C5 Lap Timer）」と聞き分けられます。
  - 長音 5 回の「接続が切れた」警告も、ほかの音に打ち切られず最後まで鳴ります。
  - 動作（接続や MSP の中継）は変わりません。

### 変更

- **USB テザリングを削除**しました（ホストモードで、USB につないだ Android スマホからインターネットへ出る機能）。うまく動かず、使う見込みもないためです。WiFi 設定ページのチェック、状態の表示、関係する処理と README の説明を消しました。ホストモードのほかの動きは変わりません。
- **ラジオボタンとチェックボックスの大きさをそろえました**。iPhone などのブラウザーで、「接続方式」は小さく、「接続先」の一覧は大きく表示されていました。すべて大きい方（22 px）にそろえました。

### 対応するファームウェア

netpack の XIAO を書き換えてください（通常版・タイマー流用版とも同じ変更）。ブリッジは書き換え不要です。

### 動作確認

- 通常版・タイマー流用版のビルドを CI で確認しました。実機での確認をお願いします。

## English

### Fixes

- Joining WiFi in client mode, the beeps sometimes came as a proper "beep beep" and sometimes as a fast "beepbeepbeep".
  - Cause: FPV C5 Lap Timer connecting (1 short) during the WiFi beeps (2 short) cut them and started over.
  - A beep asked for while another sounds now **waits its turn**: the one sounding finishes, a 0.25 s pause, then the next. Always "beep beep (WiFi) … beep (FPV C5 Lap Timer)".
  - The 5 long beeps of a lost connection are no longer cut by another beep either.
  - Nothing else changes (connections, MSP).

### Changes

- **USB tethering removed** (host mode out to the internet through an Android phone on the USB port): it didn't work well and won't be used. The WiFi page's tick box and state, the code behind them and the README's sections are gone; host mode is otherwise the same.
- **Radio buttons and tick boxes one size**: iPhone browsers drew them small in some places (the connection choice) and large in others (the networks list). All are now the large size (22 px).

### Matching firmware

Update the netpack XIAO (the same change in the standard and timerwiring builds). The bridge needs no update.

### Verified

- Both builds in CI. Please check on hardware.
